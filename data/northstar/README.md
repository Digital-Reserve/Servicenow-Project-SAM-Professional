# Northstar Manufacturing synthetic dataset

Everything here is invented for the case study: the company, people, computers, purchases and order numbers. Email addresses use the reserved `.example` domain. Publicly known product names are used only for learning.

The CSV files are generated by `scripts/generate_synthetic_data.py`, and the ServiceNow scripts in `servicenow/` are generated from them by `scripts/build_app.py`. Do not edit any of them by hand: change the generator and run both scripts. The repository check on GitHub fails if anything is out of date.

## The estate

| Object | Count | Notes |
| --- | --- | --- |
| Companies | 2 | Northstar Manufacturing and the reseller Synthetic Reseller BV |
| Locations | 3 | HQ Rotterdam, Plant North Groningen, Plant South Eindhoven |
| Departments | 6 | |
| Users | 60 | 45 of them have a laptop |
| Laptops | 45 | Windows 11, 1 processor with 8 cores, `NSM-WS-001` to `NSM-WS-045` |
| Servers | 12 | 4 Windows application servers (2 processors x 8 cores), 3 Windows SQL servers (2 processors x 4 cores), 5 Linux servers |
| Software installations | 248 | 113 licensed products, 135 free tools for the normalization exercise |
| Software usage rows | 103 | Acrobat, Visio and Project on the laptops |
| Software models | 5 | One per story |
| Entitlements | 5 | One per story |
| Allocations | 68 | Acrobat to 40 users, Project to 28 laptops |

`cpu_core_count` follows ServiceNow's meaning: cores per processor. Total cores are `cpu_count` multiplied by `cpu_core_count`.

## The five stories

| Story | Product | Counted | Owned | Used | Expected result | Money |
| --- | --- | --- | --- | --- | --- | --- |
| A | Adobe Acrobat 2024 Pro | Per named user | 40 | 40 users with an installation and an allocation | Compliant | Subscription renews 31 January 2027 |
| B | Microsoft SQL Server 2022 Standard | Per core, packs of 2, at least 4 per processor | 16 cores (8 packs) | 3 servers x 2 processors x 4 cores = 24 | Under-licensed by 8 cores | 8 x EUR 3,945 = EUR 15,780 |
| C | Microsoft Visio 2021 Professional | Per device | 60 | 35 laptops | Over-licensed by 25 | 25 x EUR 579 = EUR 14,475 |
| D | Microsoft Project 2021 Professional | Per device | 30 | 28 laptops, 12 unused for more than 90 days | Compliant, 12 removal candidates | 12 x EUR 1,059 = EUR 12,708 |
| E | Microsoft Windows Server 2022 Standard | Per core, packs of 2, at least 16 per server | 112 cores (56 packs) | 7 servers x 16 = 112 (88 actual cores) | Compliant | Shows Microsoft's minimum rule |

Prices are invented list prices in euros, so that the license check can show money.

## Files

| File | Used in | How |
| --- | --- | --- |
| `01_companies.csv` to `07_software_installations.csv` | Stage 2 | Already inside the loader script `servicenow/01_load_northstar.js` |
| `08_software_models.csv` | Stage 3 | Typed in by hand in the workspace, from the table in the guide |

| `10_allocations.csv` | Stage 4 | Inside `servicenow/02_allocate_licenses.js` |

| Script in `servicenow/` | Stage | What it does |
| --- | --- | --- |
| `01_load_northstar.js` | 2 | Creates the companies, people, laptops, servers and 248 installations |
| `02_allocate_licenses.js` | 4 | Allocates Acrobat to 40 users and Project to 28 laptops |
| `03_load_usage.js` | 5 | Adds 103 usage rows; 12 Project installations look unused |
| `00_install_workspace.js` | 1 | Fallback only: starts the Software Asset Workspace installation |

All scripts run in Scripts - Background, only touch Northstar records, and can be run again without creating duplicates.

## Rules

1. Never add real people, serial numbers, license keys or purchase orders.
2. Change the data only through the generator, then run `python3 scripts/generate_synthetic_data.py` and `python3 scripts/build_app.py`.
