# Northstar Manufacturing synthetic dataset

Everything here is invented for the case study: the company, people, devices, purchases and part numbers. Email addresses use the reserved `.example` domain. Publicly known product names are used only for learning.

The files are generated by `scripts/generate_synthetic_data.py`. Do not edit them by hand; change the generator and re-run it. The CI workflow fails if the files drift from the generator. `SUMMARY.md` is regenerated with them.

## Rules

1. Load through Import Sets with a transform map per file, in numbered order. Coalesce on the key field so re-runs update instead of duplicate.
2. Core counts on servers must be populated before reconciliation, otherwise per core results are wrong.
3. The usage file exists to drive the reclamation scenario. The reclamation engine evaluates the Software Usage table, not the installation record.
4. Never add real people, serial numbers, license keys or purchase orders.
