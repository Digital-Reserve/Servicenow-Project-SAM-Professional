# Case study: Software Asset Management Professional on ServiceNow Zurich

Status: in progress. Sections marked "filled in Session N" are completed as the guide is executed. Nothing below is claimed until its evidence file exists in `evidence/`.

## Summary

Northstar Manufacturing, a synthetic mid sized manufacturer with 60 staff, 45 workstations and 12 servers, had no view of what software was installed, what it owned, or where it was exposed. This project implemented ServiceNow Software Asset Management Professional on the Zurich release in a Personal Developer Instance and took the organisation from raw installation data to published license positions, a quantified true up exposure, quantified reusable rights, and a reclamation pipeline, in eight working sessions.

Headline results (filled in Session 7):

| Reclaimable value identified | EUR 12,708 planned (Project) |

## Context and objective

Management asked three questions: are we compliant, where are we overspending, and can we prove it in an audit. The objective was a working SAM operating model that answers all three from one system, with evidence, and that can be rebuilt from documentation if the environment is lost.

## Environment and constraints

| Item | Choice |
| --- | --- |
| Platform | ServiceNow Zurich, Personal Developer Instance |
| Application | Software Asset Management Professional, activation `com.sn_samp_master_ws`, Software Asset Workspace |
| Publisher pack used | Microsoft |
| Data | Synthetic only, generated by a script in this repository |
| Cadence | Eight sessions of two to three hours over four to seven weeks |

A Personal Developer Instance lacks the Content Service, discovery and usage feeds, SaaS License Management and outbound email. Each limit was solved rather than skipped; the table in `GUIDE.md` Appendix A lists the solution and what it demonstrates.

## Approach

The implementation follows the SAM data chain and nothing else:

installation, discovery model, normalization, software model, entitlement, reconciliation, publisher rules, reclamation, management view.

Five products were chosen so that every kind of license position appears once:

| Scenario | Product | Metric | Position | Money story |
| --- | --- | --- | --- | --- |
| A | Adobe Acrobat 2024 Pro | Per named user | Compliant | Subscription renewal 31 Jan 2027 |
| B | Microsoft SQL Server 2022 Standard | Per core | Shortage of 8 cores | True up 4 packs, EUR 15,780 |
| C | Microsoft Visio 2021 Professional | Per device | Surplus of 25 | EUR 14,475 of rights to reuse |
| D | Microsoft Project 2021 Professional | Per device | Compliant, 12 unused | EUR 12,708 reclaimable |
| E | Microsoft Windows Server 2022 Standard | Per core | Compliant | Microsoft core minimums |

## What this looks like in production

* Installations arrive from ServiceNow Discovery, SCCM, Intune or Agent Client Collector instead of import files. The same tables and discovery model logic apply.
* The Content Service keeps the content library current and raises the automatic normalization rate; manual normalization becomes the exception.
* Usage comes from Agent Client Collector or SCCM and feeds the same reclamation rules.
* SaaS License Management adds subscription usage for Microsoft 365, Adobe and others.
* Entitlements are created from publisher part numbers and purchase orders so enrichment such as downgrade rights is automatic.
* Reclamation flows send the uninstall task to the endpoint tool after approval.
* Now Assist for SAM adds AI agents for request fulfilment, reclamation rule creation and candidate evaluation.
