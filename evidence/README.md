# Evidence

Selected screenshots that prove implementation milestones. Keep only the strongest evidence.

Naming: `W<nn>_<nnn>_<Description>.png`, for example `W01_001_PDI_Zurich_Release.png`.

Recommended final set: Zurich release, SAM Workspace, normalization, entitlement, reconciliation, publisher scenario, optimization, visitor experience, final management view.

Allowed file types: png, jpg, jpeg, gif, webp, pdf, md. Remove or mask any sensitive information, including browser address bars with session parameters, before publishing.
