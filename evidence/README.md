# Evidence

Screenshots that prove each session's checks. Named `S<session>_<nn>_<what_it_shows>.png`, for example `S4_05_position_shortage.png`. The expected file names are listed in each session of `GUIDE.md` and in the evidence index of `CASE_STUDY.md`.

Allowed types: png, jpg, jpeg, gif, webp, pdf, md. Crop anything sensitive before committing, including browser address bars that carry session parameters. Never commit a screenshot that shows a password or a cookie.
