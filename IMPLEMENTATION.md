## Implementation flow

1. Provision Zurich PDI and verify the release.
2. Create the Week 01 update set.
3. Activate SAM Professional with demo data from the Developer Site; install the workspace manually if missing.
4. Validate tables, roles, scheduled jobs and workspace; record plugin versions.
5. Capture the baseline counts.
6. Confirm the Northstar Manufacturing scenarios against demo data.
7. Validate normalization using the shipped content library and manual normalization.
8. Build the inventory scenarios through Import Sets where demo data is insufficient.
9. Validate or create the five software models.
10. Create and publish the five entitlements.
11. Allocate Adobe Acrobat Pro rights to users.
12. Run reconciliation and validate compliant, shortage and surplus positions.
13. Demonstrate the Microsoft per core calculation.
14. Demonstrate reclamation candidates and savings.
15. Configure management views.
16. Harden visitor access and run negative tests.
17. Export project owned artifacts with checksums.
18. Complete acceptance testing.

## Normalization

Normalization will be demonstrated with the content library rules shipped in the plugin, demo data and normalization suggestions. The SAM Content Service is not available on a PDI and this is stated in the evidence.

## Software models and entitlements

Five models, one per scenario. Entitlements are created in the workspace, given a license metric, quantity (packs for Microsoft), unit cost and dates, then published. Draft entitlements are ignored by reconciliation.

## Reconciliation

Run from Software Asset Workspace as `sam_admin` or by the scheduled job SAM - Software License Reconciliation. Results are traced from the license metric result back to entitlement, software model and installations.

## Publisher scenario

Microsoft per core licensing for Windows Server 2022 Standard (8 cores per processor and 16 cores per server minimums, 2 core packs) and SQL Server 2022 Standard (4 core minimum per server, 2 core packs). The pack's calculation is verified in the instance before any claim is made.

## Optimization

Project Professional 2021 installations unused for more than 90 days become reclamation candidates through a reclamation rule and the Zurich Flow Designer reclamation flows. No real endpoint is affected.

## Roles

`sam_admin` for implementation, `sam_user` reviewed, visitor role designed separately as read only.

## Testing

`docs/08_TEST_ACCEPTANCE.md` defines test groups A to K. Results are recorded weekly.

## Data policy

All portfolio data is synthetic (Northstar Manufacturing) or ServiceNow demo data. The synthetic data is generated by `scripts/generate_synthetic_data.py` and documented in `docs/synthetic_data/README.md`.

## Source control and export

The licensed SAM product is not copied into this repository. Project owned global customizations are preserved through completed update set exports. A project owned scoped application, if created, may use ServiceNow Studio source control. Selected synthetic records are preserved as XML or CSV exports with checksums, verified by `scripts/verify_exports.sh`.
